## Сервис синхронизации локальной папки с облачным хранилищем
### Он автоматически будет проверять локальную папку с связанным облачным хранилищем так, что Вы всегда сможете получить доступ с другого устройства.

* Настройте файл конфигурации (config.ini)
* В main.py укажите путь к нему для SyncService относительно файла main.py
* Установите все необходимые библиотеки и запустите main.py
```commandline
pip install -r requirements.txt
python3 main.py
```
